# Video-Timing-Calculator
Video timing calculator based on ToastyX's "Custom Resolution Utility"

I find myself frequently wondering what the horizontal refresh rate and bandwidth would be for a given resolution. There are some tools to do so online, but the method I find the most reliable/accurate has been to open Custom Resolution Utility, and generate a resolution without saving it. This functionality is great, but requires access to Windows computer with CRU installed to use it. So I had Claude look over the source code for CRU, and use it as a reference to create a platform-agnostic webapp to perform the same calculations with a similar interface.

This program is based almost entirely on Custom Resolution Utility by ToastyX. CRU is a wonderful, extremely useful free piece of software I use all the time. Here is a link to their thread, and patreon:
https://www.monitortests.com/forum/Thread-Custom-Resolution-Utility-CRU
https://www.patreon.com/ToastyX
