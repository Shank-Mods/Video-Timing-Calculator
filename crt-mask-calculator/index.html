Read this as a comparison tool, not a spec.
  • These are upper bounds from mask geometry alone. Real monitors resolve less, depending on focus, spot size, convergence, bandwidth and how closely the image fills the viewable area.
  • Pitch is usually quoted at screen center and gets coarser toward the edges. Variable pitch scales every pitch value by edge ÷ center for the Edge column.
  • Near the limit, pixels beat against the mask and cause moiré, so detail is softer than the ceiling suggests.
  • Aperture grille stripes run the full height of the screen, so the mask does not limit vertical resolution. That is set by scan lines, spot size and video timing, which this calculator does not model. TVL is the square-pixel vertical equivalent for reference.
  • Slot masks assume a 1:1 ratio of vertical to horizontal slot pitch. Real tubes vary, with vertical pitch typically in the 0.2–0.5 mm range.
  • Horizontal sampling for shadow masks uses the horizontal dot pitch convention, which is how shadow-mask and grille pitches are usually compared. Vertical sampling uses the row spacing (half the diagonal pitch on a typical delta mask).
